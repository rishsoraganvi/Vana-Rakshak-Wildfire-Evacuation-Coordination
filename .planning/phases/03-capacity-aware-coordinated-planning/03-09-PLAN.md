<objective>
Build the deterministic planning core. It runs capacity-aware group-to-shelter assignment with ETA-aware costs, k=3 safe-path selection and BPR congestion passes, then validates with V1–V7. A bounded conflict resolver (at most 3 loops, fixed three-strategy menu, optional LLM choice) and a different greedy fallback planner follow. The result is a `PlanDraft` that is either valid or failed with named reasons.

Purpose: This is the heart of PLAN-03, PLAN-04 and PLAN-07. It is a pure library (no LangGraph, no DB), so Hypothesis can prove the invariants (RESEARCH primary recommendation) and the conflict loop stays out of LangGraph cycles (Pitfall 14).
Output: `planning/params.py`, `plan_core.py`, `resolver.py`, `fallback_planner.py`, and unit and property tests on the synthetic graph.
</objective>
