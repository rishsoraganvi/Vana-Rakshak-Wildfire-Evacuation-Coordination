<objective>
Fix Phase 2 review warning WR-03, folded into Phase 3 by D-17. Today no ingested weather row can satisfy the coordinator's scoped weather query: rows are stored as forecasts with origin `replay`, and incidents are always opened as `replay`, so real incidents never get a plan. RESEARCH Pitfall 5 lists four fix points: the parser's `is_forecast`, the parser's default origin, the incident insert origin, and the absence of a test proving the path end to end.

Purpose: A live incident must find live weather. Otherwise the per-cluster weather lookup (plan 03-10) fails closed for every real incident.
Output: Corrected parser and trigger origin handling, an observation fixture, unit tests, and a COMPOSE_SMOKE-gated integration test.
</objective>
