Create `scripts/check_real_data.py` with the replay_demo sys.path bootstrap and a function `check_real_data(graph_path: Path, shelters_csv: Path, settlements_csv: Path) -> dict[str, Any]`. It returns:
- `graph`: "built" with node_count, edge_count and mtime, or "missing" with the build command
- `shelters`: total rows and a count per capacity_source, plus a status of "synthetic" when every row is synthetic, "curated" when none is, otherwise "mixed"
- `settlements`: the same, using pop_source

It prints a short human-readable report plus the JSON. Exit code is 0 when everything is ready (graph built and both seeds curated), 1 when something is still pending. Pending is not an error, so CI never runs this as a gate.

Write `tests/unit/test_check_real_data.py`:
- a missing graph path plus the committed synthetic CSVs gives graph "missing" and both seeds "synthetic"
- the stub GraphML path gives graph "built" with node_count 3
- a temp CSV with capacity_source "district survey 2026" and is_simulated false gives shelters "curated"

In `docs/datasets.md`, add a "Real-data status" section describing the probe command and a status table: OSM graph pending, seed synthetic, until the checkpoints below are resolved.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-12-01 | Tampering | Malformed or malicious curated CSV (control chars, out-of-area points, absurd capacities) | medium | mitigate | `ShelterSeedRow` and `SettlementSeedRow` validation, `--dry-run` before load, the pilot-area distance test in test_seed_rows.py |
| T-03-12-02 | Repudiation | Unverified capacities presented as fact (S9) | medium | mitigate | capacity_source and pop_source required and shown on plans. docs/datasets.md records the sources. |
| T-03-12-03 | Information disclosure | Committing the large OSM cache | low | mitigate | data/ and cache/ are git-ignored (plan 03-01), and the instructions say not to commit data/ |
| T-03-12-04 | Denial of service | Overpass rate limits during the build | low | accept | One-time human-run build with retry guidance. The runtime never downloads. |
| T-03-12-05 | Information disclosure | Personal data in curated settlements | low | mitigate | Settlement-level columns only. The loader rejects unknown columns (extra="forbid"). |
</threat_model>
