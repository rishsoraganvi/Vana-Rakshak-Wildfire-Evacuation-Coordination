## Task 3 — Hotspot Clustering

**File:** `apps/ingest_worker/src/ingest_worker/clustering.py`

Implement/update `cluster_hotspots(observations, eps_deg=0.01, min_samples=3) -> list[HotspotCluster]`:

- Use `sklearn.cluster.DBSCAN` with `metric='euclidean'`
- Exclude noise points (`label == -1`)
- Per cluster: `centroid_lat/lon = np.mean(lats/lons)`, `mean_frp` from non-None FRP values
- `bbox_*` = min/max of cluster lat/lon values
- Return `[]` when observations is empty or all points are noise

## Task 5 — Fire CA Model Package

**Directory:** `apps/agents/fire/`

`pyproject.toml`: name=`agent-fire`, deps=`['wildfire_core','numpy','shapely','pyproj','scipy']`

**File:** `apps/agents/fire/src/agent_fire/ca_model.py`

Constants:
- `WIND_COEFF = 0.12`, `MOISTURE_COEFF = 0.04`, `P_BASE = 0.35`, `STEP_DURATION_MIN = 6`

Functions:

`_wind_factor(wind_speed_ms, wind_dir_deg, spread_dir_deg) -> float`
- `theta = radians(spread_dir_deg - wind_dir_deg)`
- Return `exp(WIND_COEFF * wind_speed_ms * (cos(theta) - 1))`

`_moisture_factor(rh_pct, temperature_c) -> float`
- Return `max(0.05, 1.0 - MOISTURE_COEFF * (rh_pct - 20))`

`_build_kernel(wind_speed_ms, wind_dir_deg) -> np.ndarray (shape 3x3)`
- Moore 8-neighbour: for each (dr, dc), compute direction angle, apply `_wind_factor`
- Normalise kernel so values sum to 1

`_run_single(ignition_grid, wind_speed_ms, wind_dir_deg, rh_pct, temperature_c, steps, seed) -> np.ndarray`
- `rng = np.random.default_rng(seed)`
- Each step: `spread_prob = convolve2d(grid, kernel) * P_BASE * moisture_factor`
- `new_ignitions = rng.random(shape) < spread_prob`
- `grid = clip(grid + new_ignitions, 0, 1)`
- Return final grid

`run_ensemble(centroid_lat, centroid_lon, bbox_west, bbox_south, bbox_east, bbox_north,
             wind_speed_ms, wind_dir_deg, rh_pct, temperature_c,
             resolution_m=250, seeds=(42,43,44), horizons_min=(60,180,360)) -> dict`
- `cell_deg = resolution_m / 111_320.0`; build lat/lon grid from bbox
- Ignition: 3x3 cell patch at centroid grid index (clamped to interior)
- Run `_run_single` per seed, chaining horizons (each horizon starts from previous grid)
- P50 perimeter: `burn_freq >= 0.5` across members; P90: `burn_freq >= 0.1`
- WKT: `shapely.unary_union` of per-cell `box()` polygons; `'POLYGON EMPTY'` if no burned cells
- Derived metrics: `affected_area_km2`, `spread_direction_deg` (GEOD azimuth), `spread_rate_m_per_h`
- Confidence from CV of per-seed burn areas at 3h: CV < 0.1 -> high, < 0.3 -> medium, else low
- Return dict with all 7 WKT keys + metrics

**File:** `apps/agents/fire/src/agent_fire/ensemble.py`

`compute_fire_spread(cluster, weather, bbox, resolution_m=250, seeds=(42,43,44)) -> FireSpreadResult`
- Calls `run_ensemble()`, wraps output in `FireSpreadResult` Pydantic model
