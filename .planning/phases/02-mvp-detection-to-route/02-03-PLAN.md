## Task 1 — Three Read-Only API Endpoints

**File:** `apps/api_gateway/src/api_gateway/routers/incidents.py` (new)

All endpoints require JWT viewer role (use existing `deps.current_viewer` dependency).

### GET /api/v1/incidents

Query params: `status: str | None`, `limit: int = 20` (max 100), `offset: int = 0`

Response model `IncidentSummary`:
- `incident_id: str`, `status: str`, `trigger_type: str | None`, `severity: str | None`
- `created_at: datetime`, `updated_at: datetime`, `hotspot_count: int`, `is_simulated: bool`

Query `incidents` table with optional status filter, order by `created_at DESC`, apply limit/offset.

### GET /api/v1/incidents/{incident_id}/plan

Response 200: `PlanResponse` | Response 404 if incident or draft plan not found

Response model `PlanResponse`:
- `plan_id: str`, `incident_id: str`, `version: int`, `status: str`
- `rationale_md: str`, `is_llm_fallback: bool`, `is_simulated: bool`
- `warnings: list[str]`, `created_at: datetime`
- `freshness: dict` (firms_age_min, weather_age_min from shared state)

Query latest `plan_versions` WHERE `incident_id=?` AND `status IN ('draft','pending_review')`,
ORDER BY `version DESC LIMIT 1`. Return 404 if none.

### GET /api/v1/audit/{incident_id}

Query params: `limit: int = 50` (max 200)

Response model `AuditEntryResponse`:
- `entry_id: str`, `run_id: str`, `node_name: str`, `latency_ms: int`
- `model_metadata: dict | None`, `created_at: datetime`, `has_outputs: bool`

Query `agent_runs` WHERE `incident_id=?` ORDER BY `created_at ASC` LIMIT limit.
Return 404 if incident doesn't exist.

**File:** `apps/api_gateway/src/api_gateway/main.py`

Register: `app.include_router(incidents_router, prefix='/api/v1', tags=['incidents'])`

## Task 4 — Replay Demo Script

**File:** `scripts/replay_demo.py`

Steps:
1. `load_settings()` — fail fast with a clear error if `GROQ_API_KEY` is missing
2. DB connectivity check: `SELECT 1`
3. Seed fixture:
   - Insert incident row (`status='detected'`, `origin='replay'`, `is_simulated=True`)
   - Insert 5 hotspot rows near Bandipur centroid (11.72N, 76.64E ± 0.003 deg jitter)
   - Insert 1 weather observation row (current wind 5m/s @ 45deg, RH 30%, temp 34C)
4. Run coordinator: `run_coordinator(incident_id, run_id)`
5. Poll `plan_versions` for `status='draft'` (max 60s, sleep 2s between polls)
6. Fetch plan row, fetch audit count
7. Print summary:

  <text...>

```

8. Exit 0 on success; exit 1 on timeout or unhandled exception (print traceback)

## Task 5 — Integration Test

@pytest.mark.integration
def test_full_pipeline_produces_draft_plan(seeded_incident):
    # Requires: GROQ_API_KEY, running DB
    final_state = run_coordinator(seeded_incident['incident_id'], str(uuid.uuid4()))
    assert final_state['error'] is None
    assert len(final_state['audit_entries']) == 8
    assert final_state['fire_result'] is not None
    assert final_state['rationale'] != ''
    # Verify plan row in DB
    with get_session() as s:
        plan = s.execute(select(PlanVersionRow).where(...)).scalar_one_or_none()
    assert plan is not None
    assert plan.status == 'draft'
```
