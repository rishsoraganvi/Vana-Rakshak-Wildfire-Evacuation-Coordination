## Task 1 — OSM Road Graph Package

**Directory:** `apps/agents/routing/`

`pyproject.toml`: name=`agent-routing`, deps=`['wildfire_core','osmnx','networkx','shapely']`

**File:** `apps/agents/routing/src/agent_routing/graph.py`

`load_or_download_graph(cache_path, bbox, network_type='drive') -> nx.MultiDiGraph`
- `bbox` = tuple `(north, south, east, west)` matching osmnx convention
- If `cache_path` exists: `osmnx.load_graphml(cache_path)` + log 'loaded from cache'
- Else: `osmnx.graph_from_bbox(north,south,east,west, network_type=network_type)`
  then `cache_path.parent.mkdir(parents=True, exist_ok=True)` + `osmnx.save_graphml(G, cache_path)`
  + log 'downloaded and cached'
- After loading/downloading: `osmnx.add_edge_speeds(G)`, `osmnx.add_edge_travel_times(G)`
- Return G

**File:** `apps/agents/routing/src/agent_routing/costs.py`

Constants: `FIRE_PENALTY_SAFE=1.0`, `FIRE_PENALTY_NEAR=5.0`, `FIRE_PENALTY_BLOCKED=float('inf')`

`apply_fire_penalties(G, current_perimeter_wkt, p50_perimeter_wkt, penalty_near=5.0) -> nx.MultiDiGraph`
- Returns a copy of G with `penalised_cost` edge attribute added
- Parse WKT with `shapely.wkt.loads()` (handles `'POLYGON EMPTY'` safely — `.is_empty` check)
- Per edge: compute midpoint from node `x`,`y` coords (osmnx stores lon as x, lat as y)
- If midpoint inside `current_perimeter`: `penalised_cost = inf`
- Elif midpoint inside `p50_perimeter`: `penalised_cost = penalty_near * travel_time`
- Else: `penalised_cost = travel_time`

**File:** `apps/agents/routing/src/agent_routing/router.py`

`nearest_node(G, lat, lon) -> int`
- Return `osmnx.nearest_nodes(G, lon, lat)` (note: osmnx takes X=lon, Y=lat)

`compute_route(G, origin_node, dest_node, weight='penalised_cost') -> RouteResult | None`
- `nx.dijkstra_path(G, origin_node, dest_node, weight=weight)`
- Return `None` on `nx.NetworkXNoPath`
- `total_distance_m` = sum of `length` attrs along path edges
- `estimated_travel_time_s` = sum of `travel_time` attrs
- `safety_classification`:
  - `'blocked'` if any `penalised_cost == inf`
  - `'caution'` if any `penalised_cost > travel_time` (i.e., > 1x multiplier)
  - `'safe'` otherwise
- `fire_penalty_edges` = tuple of edge keys where `penalised_cost > travel_time`
- Return `RouteResult`

## Task 2 — Groq LLM Adapter

**File:** `apps/coordinator/src/coordinator/llm/groq_adapter.py`

`generate_rationale(fire_result, weather, routes, settings) -> tuple[str, bool]`
- `time.sleep(1)` before call (rate-limit mitigation)
- System prompt: bounds LLM to grounded rationale only, no invented entities
- User message: structured `fire_result` + `weather` + `routes` dicts as formatted text
- Call `groq.Groq(api_key=settings.groq_api_key.get_secret_value()).chat.completions.create()`
  with `model=settings.llm_model`, `max_tokens=settings.llm_rationale_max_tokens`,
  `timeout=settings.llm_request_timeout_s`
- Return `(resp.choices[0].message.content.strip(), False)` on success
- On any exception: return `('[DETERMINISTIC FALLBACK] Fire spread CA: {area} km2. Routes: {n}. Human review required. (LLM error: {ExcType})', True)`

## Task 4 — LangGraph Graph Nodes

**File:** `apps/coordinator/src/coordinator/graph.py`

Each node is `def node_name(state: CoordinatorState) -> CoordinatorState`.

Node pattern — wrap every node:
```python
start_ms = time.monotonic_ns() // 1_000_000
inputs_snapshot = ...  # capture relevant inputs
# ... do work ...
latency_ms = (time.monotonic_ns() // 1_000_000) - start_ms
state['audit_entries'].append(AuditEntry(
    incident_id=state['incident_id'],
    run_id=state['run_id'],
    node_name='<node_name>',
    inputs_json=json.dumps(inputs_snapshot),
    outputs_json=json.dumps(outputs_snapshot),
    latency_ms=latency_ms,
).model_dump(mode='json'))
return state
```

**8 nodes:**

`ingest_trigger`: Load `HotspotObservation` rows for incident from DB. Set `state['hotspot_ids']`.

`run_weather`: Call `agent_weather.agent.get_weather_snapshot()`. Set `state['weather_snapshot']`.
On error: append warning, set stale placeholder snapshot.

`cluster_hotspots_node`: Call `ingest_worker.clustering.cluster_hotspots()`. Set `state['clusters']`.

`run_fire_ca`: For largest cluster by `point_count`, call `agent_fire.ensemble.compute_fire_spread()`.
Set `state['fire_result']`. Append warning if weather is stale.

`compute_route_node`: Load OSM graph via `agent_routing.graph.load_or_download_graph()`.
Apply fire penalties. For each cluster centroid, compute route to nearest unblocked exit node.
Set `state['routes']`.

`generate_rationale_node`: Call `coordinator.llm.groq_adapter.generate_rationale()`.
Set `state['rationale']` and `state['is_llm_fallback']`. Populate `model_metadata` in AuditEntry.

`assemble_plan`: Build `CoordinatorPlan` from state. Persist `plan_versions` row to DB with
`status='draft'`. Update `incidents.status` to `'planning'`.

`write_audit`: Bulk-insert all `state['audit_entries']` to `agent_runs` table in one transaction.
