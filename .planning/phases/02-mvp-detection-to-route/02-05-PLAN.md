Interface facts (verified while planning):
- networkx 3.6.1: when `weight` is a callable and the graph is a MultiDiGraph, Dijkstra calls `weight(u, v, d)`, where `d` is the dict of parallel edges keyed by edge key (each value is that edge's attribute dict). If the callable returns None, Dijkstra skips that hop. The built-in string weight does `min(attr.get(weight, 1) for attr in d.values())`.
- shapely 2.1.2: `shapely.prepare(geom)` prepares a geometry in place. `geom.intersects(line)` is true for crossings, contained endpoints and boundary touches. `contains` is false on the boundary, which was part of the bug.
- osmnx GraphML loading turns an edge `geometry` attribute into a shapely LineString when present. The bundled fixture edges carry no geometry.
- Fixture coordinates: node 1000001 (x 76.62, y 11.70), node 1000002 (76.64, 11.72), node 1000003 (76.66, 11.74). Edges run 1000001<->1000002 (travel_time 180) and 1000002<->1000003 (travel_time 270).
- A 3x3-cell, 250 m current perimeter centred on node 1000002 spans lon 76.6366313..76.6433687 and lat 11.7166313..11.7233687 (1.5 cells = 1.5 * 250 / 111320 deg).
- Baseline mypy: `.venv/Scripts/python.exe -m mypy apps/agents/routing/src apps/coordinator/src` prints only the pre-existing networkx "import-untyped" errors (4 lines). New code must add no other error kind.
